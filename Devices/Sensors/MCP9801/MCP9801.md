# MCP9801

I2C driver for the Microchip MCP9801 temperature sensor, implementing
`ITemperatureSensor`. It covers the whole register set: ambient temperature
(TA), configuration (CONFIG), and the ALERT limit registers (TSET, THYST).
The same register map is shared by the MCP9800/9802/9803; those parts differ
only in package and fixed address, so the driver works for them when
constructed with the matching address.

## Addressing

The 7-bit address is `1001 A2 A1 A0`. `DEFAULT_I2C_ADDRESS` (0x90) is all
address pins low, left-adjusted per the `II2CAccess` convention.
`AddressFromPins(a2, a1, a0)` returns the left-adjusted address for any strap.
The chip has no identification register; `Initialize` writes CONFIG, reads it
back, and treats a matching value as proof of presence.

## Measuring

At power-up the chip converts continuously at 9-bit resolution.
`Initialize` defaults to 12-bit (0.0625 °C) continuous conversion, after which
`ReadTemperature` / `GetTemperature` simply read the double-buffered TA
register. Reads are therefore non-blocking, but the first valid sample is only
available one conversion time after configuration.

`ReadTemperatureOneShot` implements the datasheet's low-power sequence. It
places the device in shutdown if it is not already, sets the ONE-SHOT bit,
polls CONFIG until the device clears it, and reads TA. The poll is bounded by
the datasheet maximum conversion time for the configured resolution
(75 ms at 9 bits up to 600 ms at 12 bits). The device is left in shutdown;
call `SetShutdown(false)` to resume continuous conversion.
`Utility::Delay_ms` must be assigned before using one-shot reads.

| Resolution | Step | tCONV typ | tCONV max |
|---|---|---|---|
| 9-bit | 0.5 °C | 30 ms | 75 ms |
| 10-bit | 0.25 °C | 60 ms | 150 ms |
| 11-bit | 0.125 °C | 120 ms | 300 ms |
| 12-bit | 0.0625 °C | 240 ms | 600 ms |

## ALERT output

`SetLimit` (TSET, default 80 °C) and `SetHysteresis` (THYST, default 75 °C)
accept any temperature; values are rounded to the chip's 0.5 °C step and
clamped to -128 °C .. +127.5 °C. In comparator mode ALERT asserts when TA rises
above TSET and releases when TA drops below THYST. In interrupt mode ALERT
asserts on both crossings and is released by any register read, including
`ReadTemperature`. The fault queue delays assertion until the configured
number of consecutive conversions agree. ALERT is open-drain and needs a
pull-up; the driver does not touch the pin.

```cpp
#include "MCP9801.h"
using namespace unitsnet_cpp;
using LowLevelEmbedded::Devices::Sensors::MCP9801;

MCP9801 sensor(&i2c, MCP9801::AddressFromPins(false, false, true)); // 0x92

MCP9801::Configuration config;
config.resolution = MCP9801::Resolution::Bits12;
config.alertMode = MCP9801::AlertMode::Comparator;
if (!sensor.Initialize(config))
{
    // No ACK or CONFIG read-back mismatch.
}
sensor.SetLimit(Temperature::from_degrees_celsius(60.0f));
sensor.SetHysteresis(Temperature::from_degrees_celsius(55.0f));

Temperature ambient = Temperature::from_degrees_celsius(0.0f);
if (sensor.ReadTemperature(ambient))
{
    float celsius = ambient.degrees_celsius();
}
```

Source: [Microchip MCP9800/1/2/3 datasheet, DS21909D](https://ww1.microchip.com/downloads/en/DeviceDoc/21909d.pdf).

Run the standalone host suite in `tests`. It checks the temperature and limit
encodings against the datasheet examples, CONFIG encode/decode round trips, the
one-shot sequence and its timeout, and I2C failure propagation. Electrical
behaviour of the ALERT pin must still be validated on hardware.
